⬇️ Download APK
~1.3 MB · Android 5.0 ke atas

Cara install:

  1. Buka link ini dari HP Android (Chrome), lalu tap tombol download di atas.
  2. Setelah selesai download, buka file-nya dari notifikasi atau folder Downloads.
  3. Kalau muncul peringatan "app tidak dikenal" / "unknown sources", pilih Install anyway / izinkan install dari sumber ini — ini normal karena app-nya belum didaftarkan ke Play Store.
  4. Tap Install, tunggu sampai selesai, lalu buka appnya dari home screen.
